# defectdojo

The umbrella. Installing this one plugin installs the whole official set.

```
/plugin marketplace add DefectDojo/agent-skills
/plugin install defectdojo@defectdojo
```

That pulls in `defectdojo-connect`, `defectdojo-triage`, `defectdojo-import`,
and `defectdojo-report`.

Requires DefectDojo Pro. See the [repository README](../../README.md).
